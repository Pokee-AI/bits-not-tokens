# Pass criteria (section 8 of the experiment brief, copied verbatim)

- **H1.** Fit a straight line to log(in-distribution object loss) versus log(documents) for each Zipf corpus, using measurement points where the loss is between 0.05 and 6 bits. Predicted slope magnitude beta = a/(1+a): 0.333 for a = 0.5, 0.500 for a = 1.0. PASS if the seed-averaged fitted beta is within 0.05 of the prediction for both a values, AND the fitted beta differs by less than 0.03 between n = 0 and n = 64 at the same a. Also report the fit to the ideal-learner closed form over the same range, since the predicted slopes are asymptotic.
- **H2.** For target T in {1000, 2000, 3000} facts stored, find by log-log interpolation the x at which each corpus (seed-averaged) first reaches T, for x = training tokens and x = bits delivered. Spread = max over corpora / min over corpora. PASS if, at T = 3000, spread in tokens >= 10 and spread in bits <= 2. Corpora that never reach T are reported as such and excluded from that T's spread, with the exclusion stated.
- **Secondary (not pass/fail).** Exposure-corrected axis I_eff = 12 * sum_k (1 - exp(-n_k / n0)), with a single n0 fitted across all corpora and seeds by least squares on log(bits_stored) versus log(I_eff). Report n0 and the spread on this axis.
- With two seeds there are no confidence intervals. Report the per-seed values and their range.

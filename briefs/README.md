# Experiment briefs

The design documents for each round, as given to the implementer, so the sequence of
questions — and the three failures — can be read in order. Section numbers refer to each
brief's own numbering. The pass/criteria sections were copied verbatim into the
`PASS_CRITERIA*.md` / `CRITERIA_v5.md` files at the repository root and committed before
each round's runs; those files, not these, are the pre-registration.

# Experiment briefs

The design documents for the two rounds this repository presents, as given to the
implementer. The criteria sections were copied verbatim into `PASS_CRITERIA_v4.md` and
`CRITERIA_v5.md` at the repository root and committed before each round's runs; those files,
not these, are the pre-registration.

| file | round |
|---|---|
| `v4.md` | The premise test, made stationary (brief v4.1) |
| `v5.md` | Is the v4 result robust? (brief v5.1) |

The three earlier design rounds (their briefs, criteria, results and code) are preserved
byte-for-byte on branch `archive/rounds-1-3`.

1. **H1.** The data-scaling exponent of the loss curve is set by the corpus's redundancy (its Zipf exponent), not by the learner.

## 3. The synthetic world

The world θ is fixed across ALL runs (world seed = 0). Only the data stream and model initialization vary with the run seed.

### 3.1 Facts

- K = 1,000,000 facts. Fact key = (subject s, relation r), with s in [0, 50000) and r in [0, 20). Key index = s * 20 + r.
- Each fact's object o is drawn once, uniformly from 4,096 values, using the world seed. Each fact is therefore worth exactly b = 12 bits.
- Popularity rank: draw one fixed random permutation of the K key indices with the world seed. Rank 1 is the most popular fact. This decorrelates popularity from subject id.

### 3.2 Vocabulary

Disjoint token ranges, in this order: PAD, BOS, EOS; 64 template tokens; 256 subject tokens; 20 relation tokens; 4,096 object tokens; 1,024 filler tokens. Round the vocabulary size up to a multiple of 64.

- A subject s is spelled with two subject tokens: (s // 256, s % 256). Two tokens are deliberate, so a fact cannot live in a single embedding row.
- Templates: 64 fixed templates, each a sequence of template tokens with length uniform in {4,...,8}, drawn once with the world seed.

### 3.3 Documents

One document = one fact:

```
BOS  template(4-8 tok)  subj_hi  subj_lo  relation  object  filler(n tok)  EOS
```

- Template: chosen uniformly from the 64 per document (6 bits of noise).
- Filler: n tokens drawn i.i.d. uniformly from the 1,024 filler tokens (10n bits of noise). Filler is resampled fresh for every document.
- **One document per row.** Pad each row to a fixed length (maximum document length for that corpus) with PAD, and mask PAD out of the loss. Do NOT pack multiple documents into one sequence. This avoids cross-document attention, which would let the model copy repeated facts from context.
- "Training tokens" always means non-PAD tokens.

### 3.4 Corpora

| Name | Fact sampling | Filler n | Max documents |
|---|---|---|---|
| Z05_n0 | Zipf over ranks, p_k ∝ k^-(1+a), a = 0.5 | 0 | 10,000,000 |
| Z05_n64 | same, a = 0.5 | 64 | 10,000,000 |
| Z10_n0 | same, a = 1.0 | 0 | 10,000,000 |
| Z10_n64 | same, a = 1.0 | 64 | 10,000,000 |
| EQ4_n16 | every fact exactly 4 times, one global shuffle | 16 | 4,000,000 |

Zipf sampling: normalize p_k over k = 1..K, build the CDF once in float64, sample with `np.searchsorted` on uniform draws. Generate data on the fly in large chunks on CPU; do not write corpora to disk.

### 3.5 Exact information counter

Maintain an int32 array `n_k` of length K counting how many times each fact has been consumed by the trainer so far. At every measurement point save:

- `facts_delivered` = number of k with n_k >= 1
- `bits_delivered` = 12 * facts_delivered
- the full `n_k` array (np.save, compressed) so the exposure-corrected axis can be computed later.

Closed forms for tests and plot overlays, for a Zipf corpus after N documents:

- Expected facts delivered: sum_k [1 - (1 - p_k)^N]
- Ideal-learner in-distribution object loss in bits: 12 * sum_k p_k * (1 - p_k)^N

## 4. Model

GPT-2-style decoder: 10 layers, d_model 512, 8 heads, MLP ratio 4, GELU, pre-LayerNorm, learned absolute position embeddings, tied input/output embeddings, no dropout, causal attention (use `F.scaled_dot_product_attention` with `is_causal=True`; PAD sits at the end of rows so no extra mask is needed). About 31M non-embedding parameters. Log the exact parameter count.

## 5. Training

- Loss: next-token cross-entropy on all non-PAD positions (the model is trained on the noise too; that is the point).
- AdamW, betas (0.9, 0.95), weight decay 0.1 (not on LayerNorm, biases, or embeddings), gradient clip 1.0.
- Batch size 128 documents. Linear warmup over 100 steps, then constant learning rate.
- Single pass. No document is ever reused except through the corpus's own sampling.

### 5.1 Measurement points and cooldown branches

Measurement points D_i: 12 log-spaced document counts from 30,000 to 10,000,000 (EQ4_n16: those D_i that are <= 4,000,000, plus 4,000,000).

For each D_i:

1. The main run (constant LR) reaches 0.9 * D_i documents. Snapshot model, optimizer, RNG and data-stream state.
2. A **branch** resumes from that snapshot and trains on documents 0.9*D_i to D_i with the learning rate decaying linearly to zero. The branch must consume exactly the same documents the main run will consume over that span (same data stream state).
3. Evaluate the branch's final weights (section 6). Record `n_k` as of D_i documents. Discard the branch; the main run continues at constant LR.

Implement this inside one process per run (snapshot in memory or to local disk, run the branch, restore). If this proves fragile, fall back to evaluating the constant-LR main run at each D_i with no cooldown, and record that in `DEVIATIONS.md`.

### 5.2 Learning rate selection

On Z05_n0 only, seed 1, train to 1,000,000 documents at LR 1e-3 and 3e-4. Pick the LR with the lower in-distribution object loss at the end. Freeze it for every other run. Record both results in `results/lr_sweep.csv`.

### 5.3 Run matrix

5 corpora x seeds {1, 2} = 10 runs. If GPUs are free after those finish, add seed 3 for all corpora. Expected wall time per run is roughly 1 to 2 hours on one modern GPU; if your smoke test projects more than 4 hours per run, stop and report.

## 6. Evaluation at each measurement point

Use a fixed evaluation seed so every checkpoint sees the same evaluation documents. Evaluation documents use a random template and zero filler (the object comes before the filler, so filler cannot affect it). All losses are reported in **bits** (nats / ln 2) on the **object token only**.

1. **In-distribution object loss** (for H1): mean object-token loss over 200,000 documents sampled from the corpus's own fact distribution. For EQ4_n16 that distribution is uniform over facts.
2. **Facts stored** (for H2), primary measure: over all facts with n_k >= 1, count the facts whose object is the model's top-1 prediction. Subtract the chance term facts_delivered / 4096. `bits_stored = 12 * facts_stored`.
3. **Control:** top-1 accuracy on a fixed random sample of 20,000 facts with n_k = 0 at that point. This should be about 1/4096. If it is materially higher, something is leaking; stop and investigate.
4. **Soft measure** (secondary): sum over delivered facts of max(0, 12 - NLL_bits), minus facts_delivered times the mean of the same quantity on the 20,000 unseen control facts. The subtraction matters: clipping at zero creates a positive bias on unseen facts that would otherwise swamp the signal.

Evaluate in large batches; evaluating up to 1M short sequences is cheap.

## 8. Pass criteria (copy verbatim into PASS_CRITERIA.md and commit BEFORE any real run)

- **H1.** Fit a straight line to log(in-distribution object loss) versus log(documents) for each Zipf corpus, using measurement points where the loss is between 0.05 and 6 bits. Predicted slope magnitude beta = a/(1+a): 0.333 for a = 0.5, 0.500 for a = 1.0. PASS if the seed-averaged fitted beta is within 0.05 of the prediction for both a values, AND the fitted beta differs by less than 0.03 between n = 0 and n = 64 at the same a. Also report the fit to the ideal-learner closed form over the same range, since the predicted slopes are asymptotic.
- **H2.** For target T in {1000, 2000, 3000} facts stored, find by log-log interpolation the x at which each corpus (seed-averaged) first reaches T, for x = training tokens and x = bits delivered. Spread = max over corpora / min over corpora. PASS if, at T = 3000, spread in tokens >= 10 and spread in bits <= 2. Corpora that never reach T are reported as such and excluded from that T's spread, with the exclusion stated.
- **Secondary (not pass/fail).** Exposure-corrected axis I_eff = 12 * sum_k (1 - exp(-n_k / n0)), with a single n0 fitted across all corpora and seeds by least squares on log(bits_stored) versus log(I_eff). Report n0 and the spread on this axis.
- With two seeds there are no confidence intervals. Report the per-seed values and their range.

## 10. Tests (pytest, CPU only, under one minute)

1. Generator determinism: same seeds give identical documents; world is identical across run seeds.
2. Closed form: for a = 0.5 and N = 200,000 sampled documents, empirical facts_delivered is within 1% of sum_k [1 - (1 - p_k)^N].
3. Document format: object token sits at the expected position; subject decoding round-trips; filler length is exactly n; PAD is masked from the loss.
4. EQ4: every fact appears exactly 4 times over the full corpus (test on a scaled-down K).
5. Learnability smoke test (GPU allowed, marked slow): with K = 2,000 facts, uniform sampling, n = 0, a 2-layer d=128 model reaches > 95% top-1 on delivered facts. If this fails, the pipeline is broken; do not launch real runs.
